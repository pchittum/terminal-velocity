# Welcome to the Terminal Velocity Talk

These are instructions for getting on with Peter Chittum's talk, Terminal Velocity. 

## A Simple Guide to Getting Ready

### Setup the Salesforce CLI

1. [Download](https://developer.salesforce.com/tools/salesforcecli) the Salesforce CLI (be sure to get the right download for your operating system).
1. Run the install, either for [Windows](https://developer.salesforce.com/docs/atlas.en-us.sfdx_setup.meta/sfdx_setup/sfdx_setup_install_cli.htm#sfdx_setup_install_cli_windows) or for [Mac](https://developer.salesforce.com/docs/atlas.en-us.sfdx_setup.meta/sfdx_setup/sfdx_setup_install_cli.htm#sfdx_setup_install_cli_macos). 
1. Open your terminal. This will either be the Windows Terminal or the Mac Terminal. There are other terminals out there. But if you're new, it's probably easiest to use the one that comes with your operating system. 
1. [Run a few commands](https://developer.salesforce.com/docs/atlas.en-us.sfdx_setup.meta/sfdx_setup/sfdx_setup_install_cli.htm#sfdx_setup_install_cli_verify) to test it out. 

It's as easy as that! 

### Get a DE Org

**Does it have to be a DE org?**

Well, technically it doesn't need to be, but it will make connecting to the org easier. This just makes it better as a first time experience. Trailhead playgrounds, sandboxes or scratch orgs all could just fine for learning the CLI. But a DE org that you know the password to is the easiest for our purposes. 

**Does it have to be a new org?**
Again, technically it doesn't. But a new org makes it less likely you'll trip over old customizations. And obviously *do not do any of the exercises in a production org*. That's a bad, bad idea. 

So if you need it, go [sign up](https://www.salesforce.com/form/developer-signup/?d=pb) for a new org now.
